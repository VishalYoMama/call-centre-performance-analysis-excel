# call-centre-performance-analysis-excel
Excel dashboard analyzing call centre performance metrics including customer satisfaction, representative efficiency, call durations, and purchase trends across cities and weekdays.

## Dataset Overview
- **Call records** with duration, representative, date, purchase amount, and satisfaction rating
- **Customer profiles** with gender, age, and city (Columbus, Cleveland, Cincinnati)
- **5 Representatives** (R01–R05) tracked across all calls

## Dashboard Covers
- Customer satisfaction ratings by representative
- Call volume by day of week
- Purchase amount trends over time
- Call duration breakdown (10–30 mins, 30–60 mins, 1–2 hrs, 2+ hrs)
- Performance comparison across cities

## Tools Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Dashboard with slicers

## Files
| File | Description |
